Beat admin

Add, reorder and remove beats without touching GitHub. Changes go live about a minute after you publish.

Connect to GitHub

The token is kept only in this browser and is sent only to GitHub. Use a token that has access to this one repository only.

How do I get a token?
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, then Generate new token.
  2. Give it any name, choose an expiry (for example 90 days), and under Repository access choose "Only select repositories" and pick your site's repository.
  3. Under Permissions, Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it, and paste it above.
